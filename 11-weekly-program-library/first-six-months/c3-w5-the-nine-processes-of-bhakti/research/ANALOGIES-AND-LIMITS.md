# C3-W5 Analogies and Limits

**Week:** The Nine Processes of Bhakti
**Rule:** Label every analogy as pedagogy. Never present an analogy as a śāstra quotation.

| Analogy | Teaching value | Source status | Failure point / limit | Younger use | Older/adult use |
|---|---|---|---|---|---|
| Nine doors, one home | Teaching value | Pedagogy | Pedagogy; still name the object of the home — Viṣṇu/Kṛṣṇa. | Nine picture doors; walk through one. | Which door is underused at home? |
| Letter without address | Teaching value | Pedagogy | Do not insult ordinary kindness; clarify bhakti’s object. | Put a stamp/address to Kṛṣṇa on a paper heart. | Rewrite a generic virtue as offered-to-Viṣṇu. |
| Toolbox again | Teaching value | Pedagogy | No ranking toolkits between families. | Pick one tool sticker. | Core tool + underused tool plan. |
