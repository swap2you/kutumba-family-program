# C2-W1 Younger Activity Pack (K–2)

**Week:** Action and Reaction: How Karma Binds  
**Memory phrase:** Choices are seeds. I want to plant service seeds.  
**Primary source:** BG 3.9 — https://vedabase.io/en/library/bg/3/9/

## Objective

Children show and say that choices plant seeds, and they choose service seeds.

## Printable set (prepare before Saturday)

1. **Seed picture cards (print 1 set):**  
   Service: help with shoes · soft words · return a toy · share crayons · wait patiently · careful carrying  
   Hurry-hurt: yank toy · shout “mine” · shove in line · hide a mess · tease · slam door (drawn gently, no gore)
2. **Service Seed Card template:** large seed outline on half-sheet; phrase strip on reverse.
3. **Line art:** `../visuals/V12/line-art-younger.svg` on US Letter.
4. **Zone signs:** “Service Garden” and “Hard Patch.”

## Core activity — Seed Steps (teacher-executable)

1. Mark two floor zones.
2. Children crouch as seeds in the center.
3. Show a card; children step toward Service Garden or Hard Patch.
4. Reset to center after each card.
5. End in Service Garden with memory phrase echo.

Full choreography lives in `teacher/YOUNGER-TEACHER-GUIDE.md` (Movement game — Seed Steps). Use that guide for timing and redirects; this pack is the printable/materials companion with the same steps summarized for table captains.

## Craft instructions — Service Seed Card

1. Color the seed.
2. Draw one helpful action.
3. Dictate a short sentence for helper to write.
4. Attach phrase strip: “Choices are seeds. I want to plant service seeds.”
5. Place in basket for parent handoff.

## Story boundary

Paraphrase seed/choices and a gentle King Nṛga care point from https://vedabase.io/en/library/sb/10/64/. No invented deity dialogue. No graphic violence. No “you have bad karma” talk.

## Printable coloring task

Color the line art; trace or sticker the memory phrase; first name only on the back.

## Backup (low prep)

Pass soft object; each child names one kind action; echo memory phrase three times.

## Materials checklist

Printed cards, zone signs, crayons, glue sticks, phrase strips, soft toss object, basket, wipes.

## Parent take-home cue (on phrase card)

“Home: plant one service seed before snack or bedtime. Say the phrase together once.”
