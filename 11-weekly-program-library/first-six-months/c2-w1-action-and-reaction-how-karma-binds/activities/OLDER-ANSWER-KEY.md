# C2-W1 Older Answer Key (Teacher only)

**Primary:** BG 3.9 — https://vedabase.io/en/library/bg/3/9/

**KUTUMBA teaching meaning (secure paraphrase target):**  
Work done for the satisfaction of the Lord frees us from bondage; otherwise action binds. Therefore act with detachment for His purpose.

**Adult memory line target:**  
Work done only for separate material interest causes bondage; work done for Viṣṇu should be performed without selfish attachment.

## Observation sheet — acceptable targets

- Notices bondage vs offered work / detachment for His purpose
- Does **not** claim the verse teaches fatalism
- Does **not** invent verse numbers
- Distinguishes teaching meaning from BBT translation label

## Worksheet secure answers

1. Work done otherwise than for the Lord’s satisfaction / work for separate material interest causes bondage.
2. Work for His purpose / for Viṣṇu, performed without selfish attachment.
3. BG 4.16–18: action and inaction confuse even the thoughtful; apparent idleness can still bind; wise vision can see non-binding work within activity — so “just stop working” is too simple.
4. Examples vary: cooking offered vs cooking only for myself; helping a sibling to serve vs helping only to be praised. Accept any clear parallel.
5. Because we must not diagnose another person’s hardship as a specific past karma; that is victim-blaming and outside KUTUMBA boundaries.
