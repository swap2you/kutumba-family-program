# C2-W1 Older Activity Pack (Grades 4–5)

**Week:** Action and Reaction: How Karma Binds  
**Essential question:** How do our actions bind or free us?  
**Primary:** BG 3.9 — https://vedabase.io/en/library/bg/3/9/

## Printables to prepare

1. Verse observation sheet (Devanāgarī / IAST / teaching meaning + four prompts)
2. Worksheet with five questions (see teacher guide)
3. Scenario cards (angry text · gift for praise · quiet repair)
4. Seed–fruit match cards (8 + 8) and Direct / Indirect / Delayed arrow cards
5. Intention–Method–Consequence diagram sheet
6. Reunification sentence strip

## Core sequence — executable steps

1. Read essential question aloud.
2. Open https://vedabase.io/en/library/bg/3/9/ and complete observation sheet (paraphrase teaching meaning; no long dump).
3. Answer worksheet questions 1–5.
4. In triads, resolve one scenario card using intention / method / consequence / repair.
5. Play **Action-Chain / Seed-Fruit Match**:
   - Match seeds to fruits.
   - Label each match direct, indirect, or delayed.
   - Build one three-link chain from a single “online post” seed.
6. Complete Intention–Method–Consequence diagram + offered before–during–after rewrite.
7. Write project contribution line for cycle artifact.
8. Write reunification sentence.

## Seed–fruit card content (print exactly)

| Seed (action) | Plausible fruit (result) |
|---|---|
| Soft private correction | Trust rebuilds |
| Public angry text | Conflict widens |
| Practice a verse daily | Memory strengthens (delayed) |
| Gift mainly for applause | Restlessness for praise |
| Careful offered help | Calm usefulness |
| Hide a mess | Later blame and rush |
| Honest apology | Repair begins |
| Idle scrolling when duty waits | Duty debt grows (delayed) |

## Scenario card prompts

- **Angry text:** Group-chat blame after a pickup miss.
- **Gift for praise:** Donation steered toward public thanks.
- **Quiet repair:** Fix sibling project; notice hunger for thanks.
