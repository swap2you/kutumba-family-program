# C1-W5 Analogies and Limits

| Analogy | Teaching value | Source status | Failure point / limit | Younger use | Older/adult use |
|---|---|---|---|---|---|
| Sparkler vs lamp | Brief flash vs lasting light. | pedagogy / śāstra-aligned | Lawful joy is not condemned; sparklers can be enjoyed with gratitude. | younger object lesson | adult discussion |
| Saltwater drink | Increases thirst rather than finishing it. | pedagogy / śāstra-aligned | Not a medical claim; pedagogical image for endless hankering. | younger object lesson | adult discussion |
| Offering plate | Enjoyment becomes service when offered. | pedagogy / śāstra-aligned | Not empty ritualism — mood and remembrance matter. | younger object lesson | adult discussion |

## Rule

Label every analogy as pedagogy. Never present analogy as if it were a śāstra quotation. Facilitators must speak the limit in the same breath as the image.
