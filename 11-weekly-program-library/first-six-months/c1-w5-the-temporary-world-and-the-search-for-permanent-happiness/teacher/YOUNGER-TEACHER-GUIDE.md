# C1-W5 Younger Teacher Guide (K–2 / Lāla–Lālī adapt)

## Objective

Children taste: **Temporary things can be used well but cannot provide permanent fulfillment.**

## Memory phrase

Pleasures born of contact have a beginning and end; the wise do not seek fulfillment in them alone.

## 40-minute core

| Min | Block |
|---|---|
| 0–5 | Settle + memory phrase echo |
| 5–15 | Story / Prem-kī-Kathā listening |
| 15–25 | Movement + hands-on object |
| 25–33 | Coloring / matching / craft |
| 33–38 | Memory card + take-home cue |
| 38–40 | Cleanup + parent handoff |

## Materials

## Boundaries

- No forced chanting volume.
- No public shame.
- Defer hard doctrine: use approved deferral line from `launch/TEACHER-READINESS-STANDARD.md`.
