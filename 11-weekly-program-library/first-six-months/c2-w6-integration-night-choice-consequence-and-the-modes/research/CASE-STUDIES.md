# C2-W6 Case Studies

All cases are **constructed for classroom use**. Do not map them onto identifiable local families. No gossip. Integration week: synthesize Cycle 2; do not add major new doctrine.

## Case 1 — Recurring Friday lateness (curriculum core)

| Field | Content |
|---|---|
| Concrete situation | A family has a recurring Friday problem. Everyone arrives late. One parent blames traffic; children blame hunger; another adult says, “This is our karma; nothing can change.” Devices stay active; food was not prepared on time; by kīrtana, irritation has already spread. |
| Mistaken conclusion | Fatalism (“nothing can change”) and/or single-person blame as the whole explanation. |
| Principle | Five-lens synthesis: action/reaction (BG 3.9), responsible next choice (BG 18.63), conditioning/modes (BG 14.5), false promise / māyā loop (BG 7.14), and a practical shelter — without new ontology. |
| Source | BG 18.63 (center) with review of BG 3.9, BG 14.5, BG 7.14 — https://vedabase.io/en/library/bg/18/63/ |
| Compassionate response | Separate what can be redesigned (prep time, device boundary, food plan) from what cannot (some traffic). Refuse public shame. |
| Family action | Choose one environmental change **and** one continuing Cycle 2 method for the off week. |
| What not to say | “This is just karma.” “You’re always the problem.” Mode nicknames. Ranking other families. |
| Optional age adaptation | K–2: puppet “rushed morning” + one helpful seed + tidy three items. Grades 4–5: run all five lenses on a card and propose one redesign. Adults: write the redesign with a minimum version if tired. |

## Case 2 — Mode-labeling after a slow morning

| Field | Content |
|---|---|
| Concrete situation | After a slow school morning, an adult calls a child “tamasic” in front of siblings and says the child “always ruins sāttvic plans.” |
| Mistaken conclusion | Modes = permanent identity labels that justify shame. |
| Principle | Modes describe binding conditions that change; the person remains a soul worthy of dignity (BG 14.5 boundary from C2-W4). |
| Source | BG 14.5 — https://vedabase.io/en/library/bg/14/5/ (review) |
| Compassionate response | Name the condition (“we’re foggy and late”) + one helpful cue; affirm the person; apologize for the nickname. |
| Family action | Run a clarity-reset (shoes, bags, earlier bedtime cue); retire the mode nickname permanently. |
| What not to say | Permanent mode labels; public spiritual diagnosis; comparing siblings’ “modes.” |
| Optional age adaptation | K–2: weather-face cards (clear / windy / foggy) without naming children. Grades 4–5: rewrite the adult sentence into a condition + action sentence. Adults: practice one apology script privately. |

## Case 3 — Ranking fear on integration/share night

| Field | Content |
|---|---|
| Concrete situation | A family whispers that tonight’s three-minute share will be “scored,” and a child refuses to speak unless they can “win.” |
| Mistaken conclusion | Integration night is a contest; devotion can be ranked. |
| Principle | Non-competitive rubric: presence, honesty, and one continuing practice are success — not comparative holiness. |
| Source | Program presentation posture / Cycle 2 integration purpose; review BG 18.63 deliberation without performance theater. |
| Compassionate response | Offer drawing-only, one-sentence, or parent-assisted formats; state aloud that families are not ranked. |
| Family action | Choose a safe share format; after share, correct philosophy privately if needed — never on a leaderboard. |
| What not to say | Score tables; announce winners; “your family is ahead/behind.” |
| Optional age adaptation | K–2: show a tool card silently. Grades 4–5: facilitate one lens for another table without grading tone. Adults: model a humble minimum-version share. |

## Facilitation note

Correct major misconceptions **after** presentations when possible. Protect dignity. Private competency notes never become a public leaderboard. No new major doctrine on integration night.
