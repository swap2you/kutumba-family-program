## Teaching purpose

Children place Must / Optional tokens into a jar to protect inquiry and kindness time.

## How to run

1. Decorate jar label: Time Gift.
2. Sort tokens: prayer/story/help vs endless screens.
3. Place one Must token first.
4. Echo memory phrase.

## Materials

Jar or cup; tokens; crayons; `visuals/v13/time-gift-jar.png`.

## Age boundary

K–2. No death scare.

## Success

Child places one Must token before Optional.
