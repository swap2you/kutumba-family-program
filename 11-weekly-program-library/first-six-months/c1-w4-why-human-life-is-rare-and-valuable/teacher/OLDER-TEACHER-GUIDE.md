# C1-W4 Older Teacher Guide (Grades 4–5)

## Objective

Students can explain: **Human life gives a rare opportunity for deliberate self-realization.**

## Essential question

What deserves protected family time?

## 40-minute core

| Min | Block |
|---|---|
| 0–5 | Hook + essential question |
| 5–15 | Short primary text observation (Śrīmad-Bhāgavatam 11.9.29) |
| 15–25 | Diagram + case discussion |
| 25–33 | Worksheet / game |
| 33–38 | Application + project link |
| 38–40 | Cleanup + parent handoff |

## Answer keys

See `activities/OLDER-ANSWER-KEY.md`.

## Boundaries

- Do not teach full other-week ontology.
- Misconception to block: Use fear or death-pressure to motivate children
- Science may illustrate habits only — never prove metaphysics.
