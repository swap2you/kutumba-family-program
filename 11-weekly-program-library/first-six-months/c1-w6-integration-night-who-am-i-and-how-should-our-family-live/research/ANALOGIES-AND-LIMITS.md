# C1-W6 Analogies and Limits

| Analogy | Teaching value | Source status | Failure point / limit | Younger use | Older/adult use |
|---|---|---|---|---|---|
| Necklace of beads | Weeks link as one life, not isolated events. | pedagogy / śāstra-aligned | No ranking beads; every family's strand is private. | younger object lesson | adult discussion |
| Family recipe card | Ingredients must combine: hearing, identity, opportunity, shelter, practice. | pedagogy / śāstra-aligned | Not culinary perfectionism. | younger object lesson | adult discussion |
| Station map | Retrieval practice strengthens memory of the chain. | pedagogy / śāstra-aligned | Not exam culture or scoring families. | younger object lesson | adult discussion |

## Rule

Label every analogy as pedagogy. Never present analogy as if it were a śāstra quotation. Facilitators must speak the limit in the same breath as the image.

## Inline requirement

The controlling facilitator guide already inlines these analogies — do not teach from a "see research" stub.
