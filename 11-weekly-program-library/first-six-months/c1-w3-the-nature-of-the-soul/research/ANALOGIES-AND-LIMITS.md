# C1-W3 Analogies and Limits

| Analogy | Teaching value | Source status | Failure point / limit | Younger use | Older/adult use |
|---|---|---|---|---|---|
| Sun and sunray | Ray shares light-nature with the sun but is not the sun. | pedagogy / śāstra-aligned | Ray is not the sun — blocks 'I am God.' | younger object lesson | adult discussion |
| Spark from fire | Same nature, dependent existence. | pedagogy / śāstra-aligned | Not independent Godhood; dependence remains. | younger object lesson | adult discussion |
| House and resident | Resident is not the house; still cares for the house. | pedagogy / śāstra-aligned | Can feel impersonal if overused — keep personhood of the jīva clear. | younger object lesson | adult discussion |

## Rule

Label every analogy as pedagogy. Never present analogy as if it were a śāstra quotation. Facilitators must speak the limit in the same breath as the image.

The controlling facilitator guide already inlines these analogies — do not teach from a "see research" stub.
