# C1-W3 Older Teacher Guide (Grades 4–5)

## Objective

Students can explain: **The jīva is eternal, conscious, individual, minute, and related to Kṛṣṇa in service.**

## Essential question

If I am a soul, how should I live?

## 40-minute core

| Min | Block |
|---|---|
| 0–5 | Hook + essential question |
| 5–15 | Short primary text observation (Bhagavad-gītā 2.20) |
| 15–25 | Diagram + case discussion |
| 25–33 | Worksheet / game |
| 33–38 | Application + project link |
| 38–40 | Cleanup + parent handoff |

## Answer keys

See `activities/OLDER-ANSWER-KEY.md`.

## Boundaries

- Do not teach full other-week ontology.
- Misconception to block: All souls are God / we are the Supreme
- Science may illustrate habits only — never prove metaphysics.
