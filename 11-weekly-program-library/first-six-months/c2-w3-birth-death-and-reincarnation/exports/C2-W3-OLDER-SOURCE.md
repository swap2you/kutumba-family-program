# C2-W3 Older Teacher Guide (Grades 4–5) — full track lesson

**Track window:** approx. 2:30–3:10 (40 minutes).

## Objective

Students explain **Birth and death are changes of dress for the eternal self — teach without fear** using BG 2.22, and reject fatalism that “nothing matters if we reincarnate.”

## Essential question

How do we speak calmly about birth and death?

## Text-observation task (10 min)

Open https://vedabase.io/en/library/bg/2/22/. Students write:

1. Who is speaking / what is the teaching setting (Kṛṣṇa to Arjuna in BG Chapter 2 — keep non-graphic)?
2. One phrase that signals continuity of the self through changing bodies.
3. One sentence paraphrase in their own words (not a long dump).
4. One thing this verse does **not** say (e.g., does not say we shop for bodies; does not say scare children).

Target paraphrase: As a person puts on new garments, giving up old ones, the embodied self similarly accepts new bodies, giving up old ones — taught calmly, without fear tactics for children.

## Diagram task

On board or `visuals/V12/` materials, label:

- Worn garment → set aside  
- New garment → accepted  
- Embodied self (*dehī*) → continues  
- **Limit box:** “Not choosing from a closet / not ghost speculation / not destination diagnosis”

Draw one arrow showing this week’s conclusion: the self continues; teach calmly.

## Scenario cards

Use the three constructed cases inline in `teacher/MAIN-FACILITATOR-GUIDE-V12.md`:

1. Child bedtime question  
2. Relative funeral language  
3. Teen fatalism (“nothing matters if we reincarnate”)

In pairs: name the mistaken conclusion + compassionate response + better family action. Prefer Case 3 if time is short — it matches this age band’s common doubt.
