# C2-W3 Family Home Practice

**Primary cue this week:** one-minute bedtime remembrance on **three nights**.

## Full version (5–15 minutes when energy allows)

1. Say the memory line once: *Birth and death are changes of dress for the eternal self.*
2. Paraphrase BG 2.22 in one calm family sentence (https://vedabase.io/en/library/bg/2/22/).
3. Do the Bedtime Remembrance Routine:
   - Cue (teeth brushing / device charging / entering bedroom)
   - One slow mahā-mantra or short approved hearing
   - One gratitude + one request for remembrance
4. End without lecture or fear talk.

## Minimum version (hard nights / grief)

One mahā-mantra + one gratitude. Still counts toward the three nights.

## Boundaries

- No scare stories before sleep.
- No diagnosing deceased destinations.
- No ghost entertainment.
- Saturday 2:00–4:00 remains the protected gathering; home practice is the daily/weekly cue.
