# C2-W3 Older Answer Key

## Worksheet — secure answers

1. Birth and death are changes of dress for the eternal self — teach without fear. (or close equivalent)
2. BG 2.22
3. Accept any faithful paraphrase of: As a person puts on new garments, giving up old ones, the embodied self similarly accepts new bodies, giving up old ones — taught calmly, without fear tactics for children.
4. Any of: scare pedagogy; diagnosing destinations; ghost speculation; choosing next body from a closet; “nothing matters if we reincarnate.”
5. Any concrete cue that includes one-minute bedtime remembrance on three nights (or clear minimum version)
6. Answers should connect calm speech + continuity of self + no fear tactics / no destination diagnosis
