# C2-W3 Older Activity Pack (Grades 4–5)

## A. Concept worksheet (write answers)

1. State this week’s conclusion in one sentence.
2. Write the primary scripture reference: _______________
3. Paraphrase BG 2.22 in your words (no copying long text).
4. Name one misconception to avoid (scare / destinations / ghosts / closet-shopping / fatalism).
5. Write one family action for the next 7 days (include bedtime remembrance).
6. Essential question: How do we speak calmly about birth and death? — answer in 2–3 sentences.

## B. Matching puzzle

Match term → meaning:

| Term | Meaning |
|---|---|
| dehī | Embodied self who continues |
| Garment analogy | Bodies change like clothes |
| Remembrance | Calm practice of recalling the Lord |
| Analogy limit | Not choosing a body from a closet |

Print as two cut columns and match, **or** write letters A–D.

## C. Scramble (optional)

1. Embodied self who continues → ________
2. Bodies change like clothes → ________
3. Calm practice of recalling the Lord → ________
4. Not choosing a body from a closet → ________

## D. Scenario response card

Pick Constructed case 3 from the facilitator guide (teen fatalism), or Case 1 if preferred.  
Write: mistaken conclusion / better response / one calm sentence you would say at home.

## E. Diagram task

On the week diagram, label garment / body / continuing self / limit box. Draw one arrow that shows this week’s primary conclusion: Birth and death are changes of dress for the eternal self — teach without fear.

## F. Source observation

Open https://vedabase.io/en/library/bg/2/22/. Write a faithful paraphrase of BG 2.22 (not a long dump). Optional support skim: https://vedabase.io/en/library/bg/2/13/ and https://vedabase.io/en/library/bg/8/6/.

## G. Project / poster component

Produce one artifact for `project/CYCLE-CONTRIBUTION.md` (C2-W3 layer): e.g., a “calm speech card” or bedtime-cue poster.

## H. Optional reflection

Circle one: I confused analogy with scripture / I stayed calm (no scare talk) / I need review.

## Low-prep backup

Pair-share essential question for 3 minutes; each writes one reunification sentence about calm speech or remembrance.
