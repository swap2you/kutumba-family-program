## Core puzzle — mode_sort_cards

**Print and cut** (situation cards — sort into Clarifying / Restless-craving / Dull-covering):

1. Devices silenced; seats set; short chant begins on time.
2. Two videos + work chat during homework; voices rise over “five more minutes.”
3. Dishes from yesterday; curtains closed; “too tired” while scrolling continues.
4. Family feels peaceful after chanting, then mocks another family’s messy entryway.
5. Fresh water, washed hands, one clear table before reading.
6. Everyone overslept feelings; no start time; lights stay dim by default.

**Rules card (print large):** Sort the *situation*. Do not write a classmate’s name in a mode column. Card 4 is a trap: calm can host pride—place under goodness-*trap* discussion, not under “winning.”

**Executable steps:**

1. Read essential question aloud.
2. Complete Mode Journal Grid using week terms.
3. In pairs, sort the six cards; justify with tendencies from BG 14.6–9 / 14.17 sense.
4. Label the concept diagram (three modes → bind embodied self → bhakti transcends; X on labeling people).
5. Respond to one constructed case in two sentences (condition + next action).
6. Write reunification sentence.
