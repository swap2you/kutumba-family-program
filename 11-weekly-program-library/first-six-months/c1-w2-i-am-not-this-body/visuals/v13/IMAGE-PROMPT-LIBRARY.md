# C1-W2 V13 Image Prompt Library Notes

Week-specific prompts for printables support and Gamma. Do not reuse C1-W1 garden/four-corners imagery as the main visual idea.

## Printable line-art briefs (implemented in Pillow)

1. **Life-stage sequence** — three respectful silhouettes (child, youth, elder) with arrows; cream ground; plum/teal outlines; no faces identifiable.
2. **Care / Self craft** — left body outline panel labeled Care; right heart/I panel labeled Self; bottom memory band.
3. **Memory phrase mat** — three large text bands with soft borders; heart accent.
4. **Care–Self diagram** — flow: stages → continues → kind speech + care.
5. **Kind-speech icons** — speech bubble, heart, water glass, repair handshake (simple).

## Gamma composition rules

- Slide-specific scenes (see `gamma/V13-GAMMA-*-DECK-PROMPT.md`)
- Contemporary family / educational diagram / tasteful study scenes
- Negative constraints always: no gore, no caricature, no temple logo, no embedded readable text, no invented deity pastimes, no identifiable real persons, no body-shame comedy
