# C1-W2 · Y04 · Kind Body-Speech Cards

**Print:** US Letter · cut cards · K–2  
**Mechanic:** Scenario cards + pointing game

---

## Teaching purpose

Practice kind speech about bodies; reject teasing without shaming the child who errs.

## Cards to print

| ID | Type | Text |
|---|---|---|
| K1 | KIND | “You’re a friend.” |
| K2 | KIND | “Bodies change. We stay kind.” |
| K3 | KIND | “I care for my body with sleep and water.” |
| K4 | KIND | “I’m sorry. That was not kind.” |
| T1 | REDIRECT | Someone teases about hair. → Point to kind repair. |
| T2 | REDIRECT | Someone laughs about height. → Point to kind repair. |
| T3 | MISTAKEN (teacher only demo) | “You’re weird looking.” → Stop; choose K1–K4. |
| T4 | MISTAKEN (teacher only demo) | “It’s just a joke.” → Stop; choose K4. |

## How to run

1. Read a redirect card.
2. Children point to a KIND card.
3. Echo the kind line together.
4. Never force children to confess real home teasing.

## Teacher key

Any KIND card is acceptable; prefer repair (K4) after hurt.
