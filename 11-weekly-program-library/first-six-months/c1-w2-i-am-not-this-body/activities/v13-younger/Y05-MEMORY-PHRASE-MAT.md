# C1-W2 · Y05 · Memory Phrase Mat

**Print:** US Letter landscape preferred · floor/table mat · K–2  
**Mechanic:** Retrieval / echo mat  
**Visual:** `visuals/v13/memory-phrase-mat.png`

## Teaching purpose

Give a stable visual anchor for the week’s memory phrase during Grow-and-Freeze and calm reset.

## Printed text (large)

> My body changes;  
> I continue  
> as the conscious self.

Small footer: Care for the body. Don’t tease bodies. · BG 2.13 family week

## How to run

1. Place mat in circle center.
2. Tap each line as children echo.
3. Use during Freeze and quiet reset.

## Materials

One printed mat (laminate if possible).
