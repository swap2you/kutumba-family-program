# C2-W5 Analogies and Limits

**Week:** Māyā: Decorating the Prison Cell
**Rule:** Label every analogy as pedagogy. Never present an analogy as a śāstra quotation.

| Analogy | Teaching value | Source status | Failure point / limit | Younger use | Older/adult use |
|---|---|---|---|---|---|
| Decorating the prison cell | Teaching value | Pedagogy | Pedagogy from the tradition’s teaching image — not a verse quotation. Do not call someone’s home “a prison” as insult. Do not shame beauty, order, or responsible householder care. | Pretty cage still has a door we need Kṛṣṇa’s help to open. | Name one upgrade that helps service vs one upgrade that only feeds image. |
| Shiny lure / sticky path | Teaching value | Pedagogy | Not a scientific proof of ontology. Do not pathologize ordinary curiosity in children. | Shiny toy vs helping hands — stop, breathe, choose help. | Map one attention chain: notice → want → click → fog. |
| Rope of the modes | Teaching value | Pedagogy | Do not turn mode language into permanent labels for people. Pair with BG 7.14 surrender. | Soft rope game: ask a friend for help to free hands. | Which soft rope (comfort, rush, fog) shows up most at home? |
