# Teacher Pre-Week Checklist — Cycle 1

Print or copy privately. Do not commit completed checklists with personal notes.

## Before each Saturday

- [ ] Read this week's objective and memory line
- [ ] Open the source packet / SOURCE-MATRIX links (do not invent URLs)
- [ ] Read misconceptions/boundaries
- [ ] Rehearse opening 5 minutes aloud
- [ ] Prepare materials from the materials list
- [ ] Prepare activity + low-prep backup
- [ ] Confirm age band (younger K–2 / older Grades 4–5)
- [ ] Review correction ladder and deferral line
- [ ] Know reunification / parent handoff time
- [ ] Confirm no private family data is written into shared folders

## Ready / not ready

| Ready if | Not ready if |
|---|---|
| Can state objective without notes | Hoping to "wing" doctrine |
| Knows one boundary | Planning to invent a story as scripture |
| Activity materials packed | No backup for restless energy |
| Knows when to defer | Planning to force disclosure |

## Reminder

Human/temple/CPO approval is separate from this checklist. Completing this list does not authorize public distribution.
